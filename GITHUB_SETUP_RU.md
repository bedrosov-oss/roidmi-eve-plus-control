# Первичная публикация

Целевой репозиторий: `bedrosov-oss/roidmi-eve-plus-control`.

Рекомендуемый режим: PUBLIC, потому что Windows-программа читает raw GitHub URL
без персонального GitHub token. Публичная сборка обезличена.

После создания пустого репозитория содержимое этого каталога нужно загрузить в
ветку `main`. Дальше GitHub Actions будет сам пересобирать latest ZIP и SHA256
после каждого изменения `app/` или `VERSION`.
